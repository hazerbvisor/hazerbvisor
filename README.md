## About

I build experimental developer tools, runtimes, and desktop-class experiences for iPadOS.

My projects explore how far the iPad can be pushed as a development platform, including native SwiftUI applications, ARM64 Linux environments, on-device compilation, coding tools, desktop-style interfaces, and local AI.

A lot of my work starts with one question:

**Can this normally desktop-only workflow run properly on an iPad?**

---

## Featured Projects

### [CodexPad Plus](https://github.com/hazerbvisor/codex-for-ipad-Plus)

A native iPadOS workspace for the open-source Codex coding agent.

The interface is built with SwiftUI while the Codex app-server runs inside an ARM64 Linux guest using Alpine aarch64.

**Focus**

`SwiftUI` `Codex` `ARM64` `Linux` `iPadOS`

---

### [CodeApp Plus](https://github.com/hazerbvisor/codeapp-Plus)

An experimental fork of Code App focused on bringing the iPad development experience closer to a full desktop IDE.

The project builds on Monaco and Code App's existing runtime while improving editor workflows, diagnostics, tabs, build tooling, and VS Code-style functionality.

**Focus**

`Monaco` `IDE` `Swift` `LSP` `iPadOS`

---

### [XTool iPadOS Port](https://github.com/hazerbvisor/xtool-ipadOS-port)

Research and development around compiling and packaging applications directly on iPadOS.

The long-term goal is a capable on-device development toolchain without depending entirely on a traditional Mac development environment.

**Focus**

`Compiler` `Swift` `ARM64` `Toolchain` `iPadOS`

---

### [HyperDroid iOS](https://github.com/hazerbvisor/HyperDroid-iOS)

An iPadOS experiment exploring a desktop-style environment with windows, applications, a taskbar, file management, and other desktop interaction patterns.

**Focus**

`Desktop UI` `Windowing` `iPadOS` `SwiftUI`

---

### [Amethyst Mod Manager iOS](https://github.com/hazerbvisor/Amethyst-modmanager-iOS)

An iOS-focused mod management project exploring a more native way to manage game modifications and related content.

**Focus**

`iOS` `Modding` `Swift` `Tooling`

---

### [iPadOS 27 Kernel Research](https://github.com/hazerbvisor/IpadOS-27-kernel-research)

A research repository for documenting and studying iPadOS kernel structures and related low-level system behavior.

**Focus**

`XNU` `iPadOS` `ARM64` `Systems Research`

## Current Direction

I am especially interested in making the iPad a more capable standalone development machine.

That includes:

- Native Swift and SwiftUI applications
- ARM64 and AArch64 runtimes
- Linux environments on iPadOS
- On-device compilers and toolchains
- IDE and editor infrastructure
- Local AI inference and MLX
- Desktop-style windowing and productivity interfaces
- Open-source developer tooling
